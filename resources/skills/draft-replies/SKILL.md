# Draft replies

For each thread you are given:

1. Read the whole thread and the code it refers to, as it is now.
2. Write a short, polite reply that answers the point directly: what changed (with the commit or file), or why nothing changed.
3. Ask a clear question when the comment is ambiguous instead of guessing.

One reply per thread. No filler, no apologies unless something was actually wrong.

Never post replies yourself. Return them through the tools you are given.
